# plex-tools on titan

Python utilities for managing the homelab Plex library (22k movies + 3k TV + 4k IPTV). Built for this specific homelab but most scripts work on any Plex server.

## Files
- `bin/` — runnable scripts
- `LICENSE`
- `README.md` — public-facing tool docs

## Common tasks
```bash
ls bin/
bin/<tool> --help
```

## Cross-references
- `../plex/` — primary target
- `../plex-overlay/` — companion bulk operations
- `../kometa/` — runs alongside; some plex-tools scripts pre-process Kometa input
